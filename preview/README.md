# Prévia

Abra index.html para revisar os textos pretos, foto, valores, quantidades e Pix solidário. Esta prévia não abre pagamentos.

A página real está em /index.html e chama /api/checkout. O checkout é gerado automaticamente com a InfiniteTag thiago_beautynorte, confirmada em api/_lib/config.js. A quantidade pode ser digitada livremente, além dos atalhos e dos controles +/−.
